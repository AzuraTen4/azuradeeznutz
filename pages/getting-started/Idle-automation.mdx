# Idle gameplay
Nothing Beats “Automation’ & Right now you can save a few click per playing


## Automation
Automation is a unique feature in-game that lets you do a thing automatically in a few clicks, whether you want to farming resources or grinding exp while do the other thing, like watching YouTube, TikTok, etc.

### Automation Farm
This automation lets you farm resources or monster loot, or both if you want to.

### Auto Moving
This automation lets move based on the coordinate you put inside of it

### Rescue (Out Of Sync)
This button is for those who getting stuck stuck due to an out-of-sync issue between the game state and the blockchain.

## Idle Hunting
Idle Hunting is similar to the automation farm, but with fewer transactions. Automation uses one transaction per monster, while Idle Hunting allows you to kill many monsters with just a single transaction. It only provides EXP for characters and equipment perks.
