# Loot Box
Loot Box is a reward chest in FTK. Each opening is powered by RISE Chain VRF (Verifiable Random Function), so every result is genuinely random and verifiable on-chain. No tricks, no manipulation, just pure RNG. 🎲

In FTK, loot boxes come in 2 types:
## Boss Loot Box 
Exclusively dropped when you defeat a boss like Ignis the Dragon, Kalyndra the Serpent and Beowulf the Wolf <br /> 
![lbdrake](/gif/lbdrake.gif) 


## Event Loot Box/Spring Chest
Available during special events or purchasable from the shop
![lootbox](/gif/lbspring.gif)

Spring Chest Contains:
- Gold Token ( 30 % Chance )
- Healing Potion Tier 3 ( 20% Chance )
- Healing Potion Tier 4 ( 10.5% Chance )
- Monster EXP Booster Tier 3 ( 8% Chance )
- Farming Perk EXP Booster Tier 3 ( 8% Chance )
- Floating Dandelion ( 7% Chance )
- Monster EXP Booster Tier 7 ( 3% Chance )
- Farming Perk EXP Booster Tier 7 ( 3% Chance )
- Rice Bag ( 3% Chance )
- Lucy Card ( 3% Chance )
- Ironwolf Card ( 3% Chance )
- Raya Card ( 1% Chance )
- Black cat ear skin ( 0.4% Chance )
- Faelin Mount ( 0.1% Chance )
