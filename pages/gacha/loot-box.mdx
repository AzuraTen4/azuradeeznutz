# Loot Box
Loot Box is a reward chest in FTK. Each opening is powered by RISE Chain VRF (Verifiable Random Function), so every result is genuinely random and verifiable on-chain. No tricks, no manipulation, just pure RNG. 🎲

In FTK, loot boxes come in 2 types:
## Boss Loot Box 
Exclusively dropped when you defeat a boss like Ignis the Dragon, Kalyndra the Serpent and Beowulf the Wolf <br /> 
![lbdrake](/gif/lbdrake.gif) 


## Event Loot Box/Seasonal Chest ( Spring / Summer / Autumn / Winter )
Available during special events or purchasable from the Wish menu. <br />
