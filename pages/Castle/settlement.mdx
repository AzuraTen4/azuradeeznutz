# Settlement
Settlement is a place that you can live in it, is like mini village of a capital kingdom. Only The King can place it anywhere in the map also make sure the place/tiles is already captured in order to use settlement utility, Each kingdom has their own unique type of settlement as you can see the image.

based on the settlement level you can do this services like Healing, Save Point, & also Fast Travel (Teleportation), but you need some resources in order to level up the settlement level 
![setlevel1](/gambar/setlevel1.png)

## Healing (Settlement Level 1)
You can do heal in the Castle/Settlement with cost 1 gold per 50 hp

## Save Point (Settlement Level 2) 💾
Save Point is a services that let you respawn in these buildings (Castle/Settlement) when your character die.

## Teleportation/Fast Travel (Settlement Level 3) 🌀
Tired of walking that taking so long? well its time to use Fast Travel, you can use Fast Travel to some buildings (Settlement/Capital).
