# Introduction
 
Welcome to For The Kingdom, This website is only guide for this game.

## What is For The Kingdom (FTK)?

For The Kingdom (FTK) is a web-based MMORPG powered by a player-driven economy and deep worldbuilding. Players can become anything: a knight, adventurer, farmer, governor, or even the ruler of a kingdom. Every character matters. Every journey is an epic.
